# 毕业项目：两周内交付一个真实功能

把前面所有模块串成一条流水线，独立跑完：
**想法 → 提问收敛 → Spec → 计划 → TDD 实现 → 自动 Review → 验证 → 上线 → 数据验证**

交付一个**真实可用**的小功能，不是玩具。

## 选题池（也可自选，须过验收）

- A. 「每日站会摘要」bot（日历 + 任务 + 待办 → 飞书群每日推送）
- B. 内网服务「健康检查 + 状态变化告警」监控
- C. 用 PostHog 数据做团队专属周报（HTML，含异常标记，每周自动生成）
- D. 自选：一个你入职后真实遇到、想解决的重复劳动

## 交付物

- PR（含 spec + 测试 + 验证证据），合并到 playground 或真实仓库
- **AI 协作日志**：哪一步是 AI 干的
- 5 分钟演示（讲师 + 1 位同事评审）
- 复盘 3 条：AI 帮你省了什么 / 哪里差点翻车 / 下两周要沉淀什么
