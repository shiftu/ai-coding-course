# Issue #23 · 审计报告把没见过的许可证算成低风险，顺便优化一下

**标签**：bug, enhancement · **优先级**：高

上周把审计报告转给法务，他们回过来问：`fontforge-bindings` 那个
`BeiTech-Commercial-1.1` 是什么东西，他们从来没见过，怎么在报告里躺在"低风险"一栏？
我自己跑了一遍，确实是这样。麻烦看一下。

他们还要我确认一个数：报告里有风险的依赖到底是几个。这个数要填进合规台账，得对得上。

另外既然要动这块，顺便一起做了吧：

1. 加个 `--fail-on <level>` 参数，风险超过这个等级就让进程退出码非 0，好挂到 CI 上卡合并
2. 报告除了 Markdown 再出一份 JSON，CI 那边要拿去统计——尤其是许可证不兼容的那些，
   要能直接筛出来，解析 Markdown 太脆了

你要是没跑过这个工具，README 上写了怎么跑。辛苦了。
